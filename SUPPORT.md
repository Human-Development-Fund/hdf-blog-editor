# Support

## For everyday users

If the skill does not activate:

1. Confirm that it is installed and enabled.
2. Start a fresh conversation.
3. Type: `Use the HDF Blog Editor to review this post.`
4. If it still fails, note the platform, skill version, model and exact prompt used.

If an output feels mechanical, inaccurate or incomplete, do not publish it. Share the source material and output privately with the HDF skill maintainer so the recurring issue can be evaluated.

## For maintainers

Ask reporters to provide:

- Platform and plan.
- Model and reasoning or effort level.
- Skill version.
- Prompt used.
- Sanitized source material.
- Output or error.
- Expected behavior.

Remove personal, donor, beneficiary and credential information before opening a repository issue.
