# Security and privacy

## Do not include sensitive information

Do not place these items in the skill, repository, fixtures or screenshots:

- Donor names, email addresses, payment details or account data.
- Beneficiary identities or precise locations that are not approved for publication.
- WordPress credentials, API keys, session cookies or private admin URLs.
- Private partner agreements, safeguarding reports or unpublished financial records.
- Photographs without the appropriate permission and organizational approval.

Redact sensitive information before attaching WordPress captures to any model.

## Treat uploaded skills as code

The skill contains an executable Python checker. Review scripts before installing a downloaded release and use only artifacts from the official repository or workspace library.

The included checker uses the Python standard library, reads the supplied HTML and prints diagnostics. It does not require network access or modify the input file.

## Reporting a concern

Report suspected data exposure, unsafe behavior or package tampering privately to the repository owner. Do not open a public issue containing sensitive data.

## Publication responsibility

The skill assists editorial work. It does not replace HDF approval for safeguarding, legal, religious, brand, image-rights or factual decisions.
